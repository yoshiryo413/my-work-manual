# my-work-manual

取り扱い説明書 v1.0.0

## 行動指針

私が大事にしているのは **義理・人情・恩返し** の3つです。

### 義理

- 頼まれた仕事は喜んで引き受ける（自身の予定がない時に限る）
- 口約束でも、引き受けたことは最後までやり切る
- 相手との関係や筋を大切にし、筋の通らないことはしない
- 筋が通っていないことについては、相手が誰であってもこちらから言及させてもらう
- 立場や損得で態度を変えない
- 特に、筋を通さず、義理を無下にし、恩を仇で返すような理不尽な対応に対しては、はっきりと声をあげる

### 人情

- 相手の気持ちや状況を想像してから動く
- 知り合いで困っている人がいれば、自分から声をかけて手を差し伸べる
- 成果だけでなく、その裏にある努力や想いにも目を向ける
- 評価に表れにくい、人として大事な細かな点にも気づく

### 恩返し

- 受けた恩は忘れず、言葉と行動で感謝を伝える
- 自分がした手助けは見返りを求めず、水に流す（「かけた情けは水に流せ、受けた恩は石に刻め」）
- 恩を受けた本人だけでなく、次の人やチームにも返していく（恩送り）
- 自分が受けた支えを、今度は誰かを支える力に変える

## 先輩方との接し方

いつもご指導いただきありがとうございます。先輩方に対しても、義理・人情・恩返しに沿って行動します。具体的には、次のことをお約束します。

- ご依頼いただいた仕事は、責任を持って最後までやり切ります
- 報告・連絡・相談を欠かさず、筋を通した動き方をします
- 先輩方の状況やお考えを汲み取り、少しでも負担を減らせるよう動きます
- お忙しいときこそ、自分から声をかけてお手伝いします
- いただいたご指導やご支援は忘れず、成果と行動でお返しします
- 教わったことを後輩やチームに引き継ぎ、次の世代へつないでいきます

### フォローと殿のお願い

こちらとしてもやるべきことは必ずやります。そのうえで、困ったときのフォローや、いざというときの殿をお願いできると心強いです。

### 率直にお伝えすることもあります

筋が通っていないと感じたことについては、先輩方に対しても率直にお伝えさせていただくことがあります。反発ではなく、より良い形で仕事を進めたいという思いからですので、ご理解いただけると嬉しいです。

## 後輩との接し方

### 私の接し方

- 関係ができていないうちに私から距離を詰めると萎縮させてしまうと思うので、基本は声をかけてもらうのを待っています。来てくれたら、しっかり応えます。
- 一緒に全力で走ってくれる方は大歓迎です。
- 質問はいつでも歓迎します。わからないことや不満の多くは、立場による見えている景色（視座）の違いから生まれるので、質問を通じて一緒に視座を上げていきたいと考えています。
- PM・PLからの指示が曖昧なときは、リソースが足りず抽象的な方針を具体化しきれていないことがほとんどです。その「抽象を具体にする」部分をお願いすることがありますが、丸投げはせず一緒に取り組みます。
- 自分に原因がないトラブルでも謝ってその場を収めてくれたときは、あとで個別に話を聞きます。経緯がわかる資料やログなどの根拠を持ってきてもらえれば、きちんと向き合います。

### 評価するポイント

後輩のみなさんについては、下の「評価観点」に加えて、次のような姿勢を評価します。

- 指示を待たず、自分から考えて動けている
- 材料が揃いきっていなくても、手を動かしながら進められている
- 自分の都合だけでなく、チームや周りのことを考えて行動できている
- 納得できない点は質問しつつ、まずは動きながら答えを探せている
- 不満を口にするより先に、まず動けている
- 自分のミスでなくても、まずは謝罪でその場を収め、すぐに解決へ動けている

## 評価観点

PL（プロジェクトリーダー）として、メンバーを評価するときに私が見ているポイントです。

### 1. ミスした後の対応

ミスは誰にでもあるので、ミス自体を責めるのではなく、その後の行動を重視します。

- ミスに気づいたら、隠さずすぐに報告・相談できているか
- 言い訳より先に、謝罪の言葉が出ているか
- 影響範囲の確認とリカバリーに動けているか
- 原因を振り返り、同じミスを繰り返さない仕組みや工夫につなげているか

### 2. チャレンジ

結果の成否だけでなく、挑戦した姿勢そのものを評価します。その上で結果も出ている場合は、追加で評価することを約束します。

- 自分の経験や役割の枠を超えて、新しいことに手を挙げているか
- 失敗を恐れずに試し、そこから学びを得ているか
- 「どうすればできるか」を考え、改善や提案を自分から出しているか

### 3. チームワーク

個人の成果だけでなく、チーム全体の成果にどう貢献したか、メンバーとどんな関係を築けているかを見ます。チームの雰囲気をよくする動きや、仕事で円滑にコミュニケーションを取れるような動きに注目しています。

- 日頃からメンバーとコミュニケーションを取り、相談し合える関係を築けているか
- 相手の立場や考えを尊重し、信頼関係を大切にしているか
- 困っているメンバーに気づき、自分から手を差し伸べているか
- 情報や知見を抱え込まず、チームに共有しているか
- 自分の担当外でも、チームの目標のために動けているか
